# iTrace 地图数据

提供与 iTrace 当前地图版本对应的完整机器可读行政边界、地区目录、来源记录和显示瓦片。

## 下载与版本

[下载完整数据包](https://github.com/ShiyiDai/iTrace-MapData/releases/download/data-2026-09-28/map-database.zip)，免费且无需购买 App。

当前版本：2026-09-27-personal-v38-changzhou-seam。逐文件 SHA-256 和压缩包校验值见 [版本记录](versions/2026-09-28-public.json)。包内保留原始来源清单，部分授权状态为历史记录；本页记录最新来源确认。

数据库依据 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) 提供，许可全文附于包内及 licenses/ODbL-1.0.txt。各来源内容的署名与原有条款继续保留。

数据经过融合、裁剪和局部修补。本仓库不包含个人照片、足迹、账号凭据或 App 业务数据库。
